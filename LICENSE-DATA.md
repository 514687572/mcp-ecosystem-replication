## What this licence does not cover

The package contains derived measurements of third-party artefacts: server
manifests, package metadata, repository metadata. Those underlying artefacts
remain under their publishers' own terms. This package ships measurements and
identifiers, not the artefacts themselves, with one exception: the verbatim
tool descriptions reproduced in the coding evidence packs, which are quoted
under fair-use provisions for research verification.

The raw registry snapshot is not redistributed, for the reason given in
`DATA_SCOPE.md`.
